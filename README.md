# Ferramenta de Correção e Depuração de Bugs em Python

Um projeto prático em Python que demonstra identificação e correção de problemas, validação de dados, tratamento de erros, registro de informações e testes automatizados.

## Recursos

- Desenvolvimento em Python
- Tratamento de erros
- Validação de dados
- Identificação e correção de problemas
- Registro de informações e erros
- Testes automatizados com pytest
- Funções organizadas e reutilizáveis
